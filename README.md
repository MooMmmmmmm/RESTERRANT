# 麦麦搭配局

### 想吃的你来定，纠结的交给它。

打开菜单看了半天，最后还是那几样？

麦麦搭配局给拿不定主意的人配一餐。你定预算，选上今天一定想吃的，拉一下摇杆，让剩下的搭配自己出现。喜欢的锁住，不合心意的再摇。

最后看清楚：**这一餐有什么、总共多少钱、优惠后一共省多少。**

[查看 MCP 接入](MCP_INTEGRATION.md) · [运行与验证记录](docs/个人版验收.md)

## 怎么玩

**先留住想吃的，再给自己一点惊喜。**

比如，今天预算50元，想吃一个汉堡。先把它选上，其他食品交给搭配机。摇到喜欢的配餐就锁住，下一次只换剩下的。已经锁住的不会被偷偷删掉，预算不够会直接提示。

三个滚轮是揭晓搭配的动画，不是只能选三件。食品少时直接看，多时展开完整餐单；套餐按完整的一份保留。

**优惠也看整餐，不让你自己凑账。**

个人版用麦当劳 MCP 试算这份餐单，展示整餐应付和接口返回的优惠金额。有适用优惠时，刮开封签看结果；没有就照实显示。确认前，对同一份餐单再核一次价，金额变了先让你看，再确认。

这里的“一共省多少”是本次官方试算给出的整餐优惠金额，不是另抽一张新券，也不是承诺所有商品统一打几折。候选和优惠比较都有范围，不承诺全店最低价。

## 这个创意想解决什么

有时你不缺菜单，只是缺一个“今天就吃这个”的决定。

完全随机，容易摇到不想吃的；自己一件件凑，又回到选择困难。这里把决定分开：预算和必吃由你掌握，剩余搭配留给随机。锁定与重摇让你可以慢慢挑到满意，而不用每次从头选。

摇杆和刮卡把选餐做得有点期待感，真实核价负责回答“这一餐花多少钱”。整餐明细最后一起看，少算几次、少纠结一会儿。

适合一个人吃饭、有预算、知道其中一两样想吃什么，却拿不定整餐主意的时候。

## 在电脑上运行

Python 3.11及以上即可，运行不需要安装第三方包。真实模式还需要网络、本人 MCP Token。调用范围澄清前不要启动真实模式；以下保留安装与启动方法供确认后使用。

```sh
python app.py
```

先在终端输入门店编号（不回显、不保存），再填写本人Token，然后在同一电脑打开 `http://127.0.0.1:8770/`。Token不写入项目，不要粘贴到聊天、命令行参数、截图或GitHub。

如果本人Codex已经配置了麦当劳MCP，可明确选择复用本地配置：

```sh
python app.py --use-codex-config
```

也支持通过安全环境管理注入 `MCD_MCP_TOKEN`。配置格式见[mcp-config.example.json](mcp-config.example.json)，里面只有环境变量占位符；实际服务地址固定为 `https://mcp.mcd.cn`。

端口占用时可加 `--port 8771`，停止用Ctrl+C。个人版只监听电脑本机；界面按手机尺寸设计，但手机不能直接访问电脑的 `127.0.0.1`。

## 这版的范围

门店由本人启动时输入，到店取餐；完整展示接口返回的当前菜单，不再受30项种子和18项上限限制；默认规格按需读取，缺少明确默认项的食品会提示核验失败。采用默认规格，每个售卖单位一份，暂不编辑特调和套餐组成。随单购选项不等同不可选，核价不传购卡参数、不购买权益。

只保留当前一轮选择，刷新即清空。没有每日次数、分享助力、购卡、积分或支付功能；也不保证营养均衡。
