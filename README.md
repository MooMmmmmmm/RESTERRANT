# 麦麦搭配局

## 想吃的你来定，纠结的交给它。

麦麦搭配局是一款为选择困难的人设计的麦当劳单品配餐工具。设好预算，留下今天最想吃的，拉动摇杆，让剩余搭配带来一点惊喜。喜欢的逐件锁住，不满意的只重摇其余部分，逐步挑到满意的一餐。

[手机网页体验](https://maimai-peican-demo.tinywand7.chatgpt.site) · [参赛报名 #812](https://github.com/M-China/mcd-developer-innovation-challenge/issues/812) · [MCP集成说明](MCP_INTEGRATION.md)

## 预算有数，搭配有惊喜

适合一个人吃饭、有预算、知道其中一两样想吃什么，却拿不定整餐主意的时候。

- **留下必吃**：自由设置预算、选择单品。预算不足时给出提示，保留你的选择。
- **拉杆配一餐**：从单品菜单中寻找搭配，三个滚轮分批揭晓；餐单可以超过三件。
- **边摇边锁**：锁住喜欢的食品，只换其余部分，减少反复挑选。
- **整餐看优惠**：优惠封签揭晓本餐金额与已有优惠；没有额外优惠也明确显示。

例如，预算50元，今天想吃巨无霸。把它设为必吃后，让搭配机补上其他食品；喜欢的小食锁住，饮品可以继续换。选餐的决定权留在你手里，随机负责发现平时没想到的组合。

菜单只放单品，过滤官方套餐、多人组合、任选组合和非食品周边。同一种食品的一份多块规格仍可保留。食品少时直接看，多时展开完整餐单。

## 体验与运行版本

| 版本 | 用途与数据 |
|---|---|
| [公开网页演示](https://maimai-peican-demo.tinywand7.chatgpt.site) | 手机直接体验预算、必吃、拉杆、锁定重摇和刮卡；采用59项MCP单品素材快照，搭配与金额为模拟 |
| 本仓库个人版 | 在本人电脑运行，使用本人授权查询菜单与适用优惠、试算餐单，并在确认前再次核价 |

公开演示中的优惠按所选素材快照的价差展示，不能兑换，也不代表当前在售或本人可用权益。个人版的金额以官方试算为准，候选与优惠比较有范围，不承诺全店最低价。

本作品提供搭配建议与餐单确认，不创建订单或支付。购买请前往麦当劳官方渠道，再次核对餐品、价格与优惠条件。

## 本机运行

需要Python 3.11及以上，不依赖第三方Python包。真实模式还需要本人MCP授权及网络连接。

**当前运行状态：Python自动MCP调用暂停，服务规则中的自动化限制与赛事开发场景的适用范围仍待明确。以下保留运行方法，待调用范围明确后使用。** 既有真实核价记录为历史验证，不代表当前持续在线。详见[MCP集成说明](MCP_INTEGRATION.md)。

```sh
python app.py
```

按终端提示输入门店编号与本人Token，输入不回显、不保存。随后在同一电脑打开 `http://127.0.0.1:8770/`。个人版仅监听本机；手机不能直接访问电脑的此地址。

本人Codex已配置麦当劳MCP时，可明确选择复用本地配置：

```sh
python app.py --use-codex-config
```

也支持安全注入环境变量 `MCD_MCP_TOKEN`，格式见[脱敏配置示例](mcp-config.example.json)。服务地址固定为 `https://mcp.mcd.cn`。不要把真实Token提交到仓库、前端或聊天。

端口占用时使用 `--port 8771`，按Ctrl+C停止。当前采用单品默认规格，每个售卖单位一份，暂不编辑特调；不购买会员权益、不消耗积分。配餐只保留当前一轮，刷新即清空。

## MCP与验证

个人版已实际使用麦当劳MCP进行菜单、优惠查询及整餐核价。当前菜单按单品筛选，默认规格按需读取；接口失败时不以模拟金额替代真实报价。

已通过26项自动测试，覆盖预算、必吃、锁定、菜单筛选、单品券、报价异常与接口隔离。Python入口及本机HTTP流程已使用测试替身验证；手机页面已检查320和390宽度下的菜单、优惠封签与锁定重摇。

```sh
python -m unittest discover -s tests -v
```

[个人版验收记录](docs/个人版验收.md)区分测试替身与历史真实核价。[菜单与详情记录](docs/verify-live-menu-results.json)保留一次113项原始菜单及两个详情样本的只读验证；当前[公开素材快照](data/menu-snapshot.json)筛选为59项单品，未对其逐一重新核价。
