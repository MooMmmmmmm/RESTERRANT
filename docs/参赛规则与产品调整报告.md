## 产品最终范围与本次改动

名称：麦麦搭配局。解决“预算有限、知道想吃什么但不知道如何搭配”的问题。保留必吃与已锁食品，用随机动画发现其余组合，再由官方整餐核价控制预算。

1. 两步页面：预算与必吃 → 摇出餐单并确认。删除第三页和省钱/丰富路线。
2. 自由金额输入与滑动预算；真实优惠后应付不超过预算。锁定不偷偷更换餐单；全锁仍能确认，不能继续摇。无解提供调整入口，不擅自删必吃。
3. 三滚轮只是动画，食品数量不受三个槽限制。四项以内直接显示，多项展开完整清单。
4. 同步最新机身、拉杆、错峰滚轮与刮卡/封签动效。优惠只揭晓实际接口结果，没有优惠就隐藏；不虚造.99价、固定七折、随机新券。
5. 个人版确认前对同一餐单再次官方核价；价格变化先展示再确认，超预算或停售则停止确认。确认的是餐单，不产生订单或付款；购买需到官方渠道再次核对。
6. 公开站将“演示结算”改为“查看演示餐单”，避免暗示下单。每日次数、分享重刮、会员购卡、积分和支付均未加入。

老虎机仅为无付费、无奖品的配餐动画；不加入押注、中奖或兑换宣传。活动禁止宣扬赌博，这属于我们的内容风险控制，并非官方已认可此表现形式。
